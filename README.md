# 🍅 App Pomodoro Profesional

Una aplicación de temporizador Pomodoro minimalista, moderna y altamente eficiente construida con Vanilla JavaScript, HTML y CSS. Diseñada para mantener el enfoque y aumentar la productividad.

## ✨ Características Principales

* **Cero Dependencias:** Construida 100% con Vanilla JS, sin necesidad de Node.js, `npm` ni librerías de terceros.
* **Interfaz Oscura Optimizada:** Tema negro puro (Pure Black), ideal para monitores OLED y para reducir la fatiga visual.
* **Sistema de Pestañas:** Transición fluida entre tiempo de enfoque (25 min), descanso corto (5 min) y descanso largo (15 min).
* **Notificaciones Sonoras:** Utiliza la Web Audio API nativa del navegador para generar alertas sonoras sin necesidad de cargar archivos multimedia externos.
* **Sincronización de Título:** El tiempo restante se muestra en la pestaña del navegador para una fácil visualización mientras trabajas en otras ventanas.

## 🚀 Cómo usar

Dado que es una aplicación web independiente, no requiere instalación ni configuración previa.

1. Clona este repositorio o descarga el archivo `pomodoro.html`.
2. Haz doble clic sobre el archivo `pomodoro.html` para abrirlo en cualquier navegador web moderno (Chrome, Firefox, Safari, Edge).
3. Selecciona el modo que desees (Pomodoro, Descanso Corto, Descanso Largo).
4. Haz clic en **Iniciar** para comenzar la cuenta regresiva.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de la aplicación.
* **CSS3:** Estilos, animaciones, variables nativas y diseño responsivo.
* **JavaScript (ES6+):** Lógica del temporizador, manipulación del DOM y Web Audio API.
